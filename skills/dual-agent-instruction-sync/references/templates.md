- (최상위 폴더의 역할을 한 줄씩)

## 하위 폴더 AGENTS.md (포인터 전용)

```markdown
# {{폴더 이름}}

이 폴더의 규칙은 루트 `AGENTS.md`의 "{{섹션 이름}}" 섹션에 있다.
계층적으로 하위 파일을 읽는 에이전트만 이 파일을 보므로,
여기에 규칙 본문을 두면 다른 에이전트는 그 규칙을 따르지 않는다.
규칙 본문을 이 파일로 복원하지 말 것.
```

## 인수인계 노트

```markdown
# AI 에이전트 작업 인수인계

## 현재 진행 중

| 작업 | 담당 에이전트 | 상태 | 다음 행동 |
|------|--------------|------|-----------|
|      |              |      |           |

## 기록

### {{YYYY-MM-DD}} — {{에이전트 이름}}
- 상태: 완료 / 중단 / 확인 필요
- 변경 파일: {{경로 목록}}
- 결과: {{한두 줄}}
- 의존한 스킬: {{이름}} ({{공용 / 특정 에이전트 전용}})
- 다음 행동: {{한 줄}}
```

완료된 항목은 표에서 빼고 기록 섹션에만 남긴다. 자격 증명과 불필요한 개인정보는 적지 않는다.
