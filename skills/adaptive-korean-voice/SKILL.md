# 사용자 말투를 배우는 한국어 출력 스킬

한국어를 막연히 “사람처럼” 바꾸지 않는다. 사용자가 실제로 쓰는 문장의 길이, 거리감, 정보 밀도와 형식을 먼저 파악한 뒤 그 사람에게 맞는 별도 스킬을 만든다.

## 모드 선택

- 사용자가 `내 말투를 배워`, `한국어 출력을 개인화해`, `내 스킬로 만들어`라고 요청하면 **프로필 만들기**로 간다.
- 이미 개인용 스킬과 `references/voice-profile.md`가 있으면 **프로필 적용**으로 간다.
- 개인 프로필 없이 한국어 문장만 자연스럽게 다듬어 달라면 [자연스러운 한국어 기준](references/natural-korean.md)만 적용한다. 프로필 생성을 강요하지 않는다.

## 프로필 만들기

이 모드에서는 [프로필 조사법](references/profiling.md)을 읽는다.

1. 현재 대화에서 사용자가 직접 쓴 한국어 표본을 찾는다. AI가 쓴 답변, 인용문, 제삼자의 메시지는 표본으로 쓰지 않는다.
2. 표본이 짧거나 한 가지 상황에 치우쳤다면 평소 메시지나 글 3~5문장을 한 번만 요청한다. 이미 충분하면 묻지 않는다.
3. 문장 길이, 종결어미, 직설성, 정보 밀도, 단락·목록 습관, 자주 쓰는 연결어와 피하고 싶은 표현을 분석한다.
4. 확신이 낮거나 두 방향이 모두 자연스러울 때만 같은 내용의 A/B 문장 두 개를 보여 주고 어느 쪽이 가까운지 한 번 확인한다. 조사와 확인을 합쳐 최대 두 차례로 끝낸다.
5. 원문을 복사하지 않고 추상화된 규칙만 `voice-profile.md`로 만든다. 실명, 연락처, 거래처, 프로젝트명과 민감한 원문은 저장하지 않는다.
6. 분석 결과가 대화체 한 종류뿐이면 문서체까지 아는 척하지 않는다. 확인되지 않은 영역은 `기본값` 또는 `미확인`으로 표시한다.

사용자가 개인 스킬 생성을 요청했고 로컬 파일 쓰기가 가능하면 동봉된 생성기를 사용한다.

```bash
python3 scripts/create_personal_skill.py create \
  --name korean-voice-USER_SLUG \
  --display-name "USER_NAME Korean Voice" \
  --profile /path/to/voice-profile.md \
  --output-dir /path/to/skills
```

- `USER_SLUG`, 경로와 표시 이름은 실제 값으로 바꾼다.
- 기존 폴더를 덮어쓰지 않는다. 같은 이름이 있으면 멈추고 사용자의 선택을 받는다.
- Claude와 Codex가 함께 쓰는 `~/.agents/skills` 구조가 이미 확인된 환경에서는 그 경로를 우선 제안할 수 있다. 다른 환경에서 경로를 추정하지 않는다.
- 로컬 쓰기가 불가능하면 프로필과 개인 스킬 파일을 완성된 형태로 제공하되, 설치됐다고 말하지 않는다.

## 프로필 적용

개인용 스킬에서는 매 한국어 작성 작업 전에 `references/voice-profile.md`를 읽고 다음 순서로 판단한다.

1. 현재 사용자의 명시적 요청
2. 사실·안전·수신자·장르에 필요한 형식
3. 저장된 말투 프로필
4. 일반적인 한국어 자연스러움 규칙

현재 요청과 오래된 프로필이 충돌하면 현재 요청을 따른다. 사용자가 말투가 바뀌었다고 하면 새 표본으로 프로필만 갱신할 수 있다.

```bash
python3 scripts/create_personal_skill.py update \
  --profile /path/to/new-voice-profile.md \
  --target /path/to/korean-voice-USER_SLUG
```

업데이트는 기존 프로필을 `.bak`으로 보관하고 나머지 스킬 파일은 건드리지 않는다.

## 출력 원칙

- 처음부터 프로필에 맞춰 쓴다. 어색한 초안을 만든 뒤 단어만 치환하지 않는다.
- 짧은 답변은 짧게 둔다. 모든 답변을 서론·본론·결론이나 3개 목록으로 만들지 않는다.
- `중요하다`, `효과적이다`, `핵심` 같은 단어를 금지어로 취급하지 않는다. 같은 문단에서 반복되거나 구체적인 뜻을 가릴 때만 고친다.
- 사용자 원문을 윤문할 때는 사실, 숫자, 고유명사, 인과관계, 부정, 직접 인용과 격식 수준을 보존한다.
- 원문에 없는 근거, 수치, 사례, 감정, 약속을 보태지 않는다.
- 사용자가 전면 재작성을 요청하지 않았다면 어절 기준 변경량을 대략 25% 안쪽으로 유지한다. 이를 넘길 것 같으면 최소 수정본을 먼저 낸다.
- 분석표, 자연도 점수, 수정 내역은 사용자가 요청한 경우에만 보여 준다. 평소에는 최종 결과만 자연스럽게 출력한다.
- 오타와 비표준 표기는 말투로 학습하지 않는다. 반대로 문장 파편, 말줄임, 조사 생략은 대화 맥락에서 반복될 때 말투로 인정할 수 있다.

최종 확인에는 [자연스러운 한국어 기준](references/natural-korean.md)의 의미 보존 점검을 사용한다. 이 스킬의 출처와 변형 범위는 [출처와 라이선스](references/attribution.md)에 기록돼 있다.
