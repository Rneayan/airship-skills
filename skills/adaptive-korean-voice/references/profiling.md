# 말투 프로필 조사법

## 목표

사용자를 흉내 내는 과장된 캐릭터를 만들지 않고, 그 사람이 편하게 읽을 수 있는 한국어 출력 기준을 만든다. 한 번의 우연한 표현보다 반복되는 선택을 우선한다.

## 1차 조사

가능하면 현재 대화의 사용자 작성 문장 3개 이상 또는 한국어 약 150자 이상을 본다. 분량보다 서로 다른 상황의 표본이 더 중요하다.

다음 축을 `높음 / 중간 / 낮음 / 미확인`과 짧은 근거로 정리한다.

| 축 | 확인할 것 |
|---|---|
| 기본 거리감 | 반말, 해요체, 합니다체와 호칭 |
| 문장 리듬 | 짧은 문장, 긴 설명, 파편 문장, 줄바꿈 |
| 직설성 | 결론 우선, 완곡 표현, 제안과 단정의 강도 |
| 정보 밀도 | 요약 선호, 근거 요구, 세부 설명 허용 범위 |
| 구조 | 평문, 번호 목록, 표, 헤더 사용 습관 |
| 어휘 | 일상어·전문어 비중, 한자어와 영어 허용 범위 |
| 감정 온도 | 건조함, 친근함, 유머, 이모지와 감탄사 |
| 교정 강도 | 오타만 수정, 최소 윤문, 적극 재작성 |

한 가지 표본으로 성격이나 신원을 추정하지 않는다. 오타, 음성 입력 흔적, 급하게 쓴 축약형은 반복되지 않으면 선호로 기록하지 않는다.

## 부족할 때 묻는 질문

질문은 필요한 것만 한 번에 묻고 답을 강요하지 않는다.

- “평소에 직접 쓴 메시지나 설명글 3~5문장을 붙여 주세요. 개인정보는 지워도 됩니다.”
- 격식 선택이 불분명할 때만 “평소 AI 답변은 해요체와 합니다체 중 어느 쪽이 더 편한가요?”

이미 대화에 충분한 표본이 있으면 같은 질문을 하지 않는다.

## 2차 확인

프로필의 핵심 선택이 불확실할 때만 3~4문장의 중립적인 내용을 두 버전으로 만든다.

- A는 더 짧고 대화적인 버전
- B는 조금 더 정돈되고 설명적인 버전

내용과 정보량은 같아야 한다. 사용자가 고른 방향과 한 줄짜리 수정 의견을 반영하고 조사를 끝낸다. 사소한 표현 하나마다 추가 질문하지 않는다.

## 프로필 형식

```markdown
---
profile_version: 1
profile_name: 사용자 표시 이름
status: personalized
created: YYYY-MM-DD
sample_scope: conversation | supplied-text | mixed
---

# 한국어 말투 프로필

## 핵심 목소리
- 기본 거리감:
- 리듬과 길이:
- 직설성과 온도:

## 상황별 문체
- 일상 대화:
- 정보 정리:
- 외부 발송문:

## 형식
- 선호:
- 피함:

## 표현
- 유지할 특징:
- 줄일 표현:
- 금지어가 아니라 문맥으로 판단할 표현:

## 윤문 경계
- 기본 교정 강도:
- 반드시 보존:
- 확인 전 확장 금지:

## 신뢰도와 미확인 영역
- 높은 신뢰:
- 미확인:
```

프로필에는 원문 예시를 넣지 않는다. 꼭 필요한 짧은 예가 있더라도 개인정보와 고유명사를 제거하고 10단어 안쪽으로 제한한다.
