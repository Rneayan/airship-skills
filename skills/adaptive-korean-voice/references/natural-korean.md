# 자연스러운 한국어 기준

## 먼저 지킬 것

1. 현재 요청과 수신자에게 맞는 격식을 유지한다.
2. 사실, 숫자, 날짜, 고유명사, 인과관계, 부정 표현과 직접 인용을 바꾸지 않는다.
3. 전문 용어와 사용자가 의도적으로 고른 단어는 쉬운 말로 억지로 바꾸지 않는다.
4. 자연스러움보다 정확성이 중요한 문장에서는 정확성을 우선한다.

## 고칠 가능성이 높은 패턴

아래 표현은 금지어가 아니다. 가까운 문장에서 반복되거나 뜻을 흐릴 때만 고친다.

- `이를 통해`, `~에 대해`, `~에 있어서`, `~할 수 있다`, `~것이다`의 연속 사용
- `효과적`, `핵심적`, `혁신적`, `다양한`, `지속 가능한`처럼 근거 없이 붙는 추상 형용사
- `진행하다`, `실시하다`, `수행하다`, `도출하다`처럼 간단한 동사로 충분한데 격식을 더하는 말
- 문맥상 복수가 분명한데 반복되는 `-들`
- 바로 앞의 대상을 다시 가리키는 `이것은`, `그것은`, `해당`
- 같은 주어와 같은 종결어미가 기계적으로 이어지는 문장
- 모든 내용을 정확히 세 항목으로 맞추는 목록과 불필요한 결론 문구
- 영어 어순을 따른 긴 명사구, 과도한 피동과 이중 피동

## 자연스럽게 만드는 방법

- 추상적인 평가를 빼고 이미 주어진 구체적인 사실을 앞으로 보낸다.
- 한국어에서 문맥상 분명한 주어와 목적어는 생략할 수 있다.
- 명사형 표현이 겹치면 동사나 형용사로 풀어 쓴다.
- 문장 길이를 일부러 들쭉날쭉하게 만들지 말고, 생각 단위에 맞춰 끊는다.
- 대화체에서는 문장 파편과 조사 생략을 허용하되 읽기 어려운 오타까지 흉내 내지 않는다.
- 공식 문서에서는 필요한 한자어와 관용 형식을 유지한다. 가벼운 말투가 항상 더 자연스러운 것은 아니다.

## 과교정 방지

- 이미 자연스러운 짧은 문장은 띄어쓰기와 명백한 어색함만 고친다.
- 사용자의 개성 있는 표현을 일반적인 AI 문장으로 평준화하지 않는다.
- 원문에 없는 수치나 사례를 만들어 “구체화”하지 않는다. 근거가 없으면 추상 표현을 줄이는 선에서 멈춘다.
- 같은 뜻의 평범한 단어를 낯선 순우리말이나 과한 구어체로 바꾸지 않는다.
- 전체 문장을 다시 쓰는 편이 낫더라도 사용자가 요청하지 않았다면 최소 수정본을 우선한다.

## 조용한 최종 점검

출력 전 내부에서만 확인한다.

- 요청한 내용에 바로 답했는가?
- 원문에 없던 사실이나 감정을 추가하지 않았는가?
- 존댓말 수준과 장르가 유지됐는가?
- 같은 연결어, 주어, 종결어미가 눈에 띄게 반복되지 않는가?
- 문장을 짧게 만들다가 조건이나 예외를 잃지 않았는가?
- 말투 프로필보다 현재 사용자의 명시적 요청을 우선했는가?

사용자가 분석을 요청하지 않았다면 이 점검표를 출력하지 않는다.
