# 한국어 비즈니스 메시지 교정

1인 스튜디오 대표·프리랜서·강사처럼 클라이언트, 협업사, 학교와 직접 소통하는 사용자의 업무 메시지를 교정하는 스킬.

## 핵심 원칙: 최소 수정 (Minimal-Touch)

**절대 규칙**: 사용자의 말투와 문체를 유지한다. 재구성·전면 재작성 금지.

- 수정 범위: 맞춤법, 띄어쓰기, 오타, 명백히 어색한 문장 1~2곳
- 문단 구조, 어순, 표현 스타일은 사용자 원문 그대로 유지
- 전면 개선이 필요해 보여도 먼저 최소 수정본을 제시하고, 필요 시 개선 제안은 별도로 언급

## 채널별 포맷 규칙

메시지를 어디로 보내는지 먼저 파악하거나 물어볼 것. 채널에 따라 출력 형식이 다르다.

| 채널 | 포맷 규칙 |
|------|-----------|
| **카카오톡** | 마크다운 금지. 플레인 텍스트만. 줄바꿈으로 가독성 확보. 친근한 공지라면 이모지 소량 허용 |
| **Slack** | `#` 헤더 문법 지원 안 됨. `*굵게*`(별표 1개), `-` 불릿 사용. 복사용 코드블록으로 제공 |
| **이메일** | 격식체. 인사말–본문–맺음말 구조. 번호 목록 활용 가능 |
| **교수님/학교** | 가장 격식 있게. 겸손하고 감사를 표하는 맺음말 유지 |

## 자주 나오는 교정 패턴

1. **붙여쓰기/띄어쓰기**
   - "전달 드립니다" → "전달드립니다"
   - "홍길동 입니다" → "홍길동입니다"
   - "확인 해 주셔야하고" → "확인해 주셔야 하고"
   - "진행 해야 합니다" → "진행해야 합니다"
   - "지난토요일" → "지난 토요일"
2. **오타**: "곂쳐" → "겹쳐", "선전" → "선정", 서비스명은 공식 표기로 (예: "아트리스트" → "Artlist")
3. **군더더기 제거**
   - "~할 수 있도록 하겠습니다" → "~하겠습니다"
   - "확인 완료 했습니다" → "확인했습니다"
   - 과도한 존칭·필러 문구
4. **어색한 표현 다듬기**: "불가능하고" → "참석이 어려우며" (격식 상황), "스케줄" → "일정"

## 작업 절차

1. 메시지의 수신자(클라이언트/교수/팀원)와 채널(이메일/카톡/Slack) 파악
2. 최소 수정 원칙으로 교정
3. 채널 포맷에 맞게 출력
4. **수정 내역을 마지막에 반드시 명시** — 무엇을 바꿨고 무엇을 유지했는지 (변경 사항의 투명성)
5. 사용자가 직접 고쳐온 버전을 평가해달라고 하면, 전체 재작성 대신 해당 문장만 타겟 수정

## 톤 참고

- 기본 문체: 격식 있지만 직설적이고 깔끔함. 과한 사과·존칭 없음
- 클라이언트 대상: 정중하되 담백하게. 지연 사과는 짧게 한 번만
- 기술 설명(예: AI 제작 파이프라인) 시: 상대가 비전문가일 수 있으므로 전문용어 없이 순차적 흐름으로 설명, 핵심어는 굵게(채널이 지원할 때만)
