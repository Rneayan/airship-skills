# AI 공모전·영화제 DB 관리

사람은 **현재 참여할 만한 행사와 조건**을 먼저 읽고, AI는 별도 지침과 누적 이력으로 작업을 이어간다. 기존 공모전 폴더와 PARA 체계를 따르며 실제 경로·파일명·명명 규칙은 사용자 환경에 맞춘다. 특정 볼트의 폴더 번호나 개인 출품 전략을 공통 규칙으로 강제하지 않는다.

## 시작할 때

- 현재 사용자 요청, 볼트의 공유 지침·네이밍 규칙, 공모전 폴더의 전용 AI 지침을 먼저 읽는다. 기존 문서·첨부·최근 조사 이력과 이전 에이전트의 인수인계를 확인한다.
- 전용 지침이 있으면 그 문서를 로컬 작업 기준 정본으로 사용한다. 이 스킬은 일반적인 방법을 제공하며 경쟁 사본을 만들지 않는다.
- 기존 자료가 있으면 같은 정보시트·후보 상세·누적 이력을 갱신한다. 구조 개편은 사용자 요청 범위에만 적용하고 다른 프로젝트나 볼트 전체를 함께 재편하지 않는다.

## 문서 역할을 나눈다

아래 이름은 기본 예시다. 기존 이름이 있으면 유지하거나 사용자 명명 규칙에 맞춘다.

| 문서·위치 | 역할 | 관리 방식 |
|---|---|---|
| `AI 영화제 정보 시트.md` | 사람용 전체 현황 | 첫 본문은 국내외를 합친 **마감일순 공모전 목록** |
| `공모전·영화제 참여 후보 목록.md` | 사람용 선택·상세 조건 | 먼저 검토할 후보, 행사별 자격·규격·비용·권리·출처 |
| `AI 공모전 작업 지침.md` | AI용 폴더 운영 기준 | 갱신·출처 확인·아카이브·기록 절차. 보고 문서에는 링크만 |
| `조사·정리 기록/공모전 조사·정리 이력.md` | 누적 작업 기록 | 같은 문서의 작업 목록과 상세 이력에 계속 추가 |
| 기존 개별 노트·첨부 폴더 | 공식 요강·상세 조사 근거 | 필요할 때만 추가. 모든 후보마다 파일을 만들지 않음 |
| 기존 아카이브 폴더·목차 | 종료된 모집·지난 자료 | 현재 후보와 구별하고 이동·연결 이력 유지 |

### 정보시트 — 결과 먼저

- 제목과 짧은 기준일 안내 다음에 공모전 표를 둔다. `현재 후보와 정리 결과`, 운영 기준, AI용 요약, 검증 로그, 과거 조사 원문을 표보다 앞에 넣지 않는다.
- **실제 최종 접수 마감일순**으로 국내외를 합친다. 같은 날짜의 확인된 종료 시각도 반영하되 해외 시간대를 임의 환산하지 않는다. 조사일·개최일·접수 시작일을 마감일처럼 정렬하지 않는다.
- 기본 컬럼은 `마감 / 공모전·영화제 / 분야 / 시상·보상 / 확인 상태`. 비용·규격·제출 방법·권리는 연결된 상세에서 읽는다.
- 행사명을 누르면 상세 노트나 후보 문서의 해당 앵커로 이동한다. Markdown 표 안의 Obsidian 별칭 링크는 `[[대상\|표시명]]`처럼 구분자를 이스케이프해 열이 깨지지 않게 한다.
- 접수 예정·마감 미정, 자격 제한, AI 작품 허용 미확인·보류는 별도 표로 분리한다. 종료 시각이 불명확한 행사는 그 상태를 표시한다.

### 후보 상세 — 참여 판단 중심

- 먼저 검토할 후보를 제작 분량·관심 분야·비용·일정·권리 조건으로 설명한다. 추천 개수는 사용자 상황과 조사 결과에 맞추며 수상 가능성 예측으로 표현하지 않는다.
- 행사별 본문은 **마감·참가 대상·시상·비용 → 만들 작품과 제출 방법 → 참여 전 확인할 조건 → 출처** 순서다. 짧은 표와 문장·목록을 쓰고 내부 A/B/C 코드나 작업 절차를 독해의 전제로 만들지 않는다.
- 접근 실패·도구 오류, 파일 이동 설명, 해시 검증, 과거 개인 전략은 누적 이력으로 보낸다. 자격·이용권·비용·최신 요강 미확인처럼 선택에 필요한 정보는 상세에 남긴다.
- 날짜순 전체 목록은 정보시트에, 추천과 상세는 후보 문서에 관리한다. 겹치는 마감·시상·상태는 함께 갱신한다. 기존 ID·제목 앵커·개별 노트 링크를 보존한다.

## 조사와 상태 판단

- 영상·이미지·광고·음악·캐릭터·문학·지자체 행사·국제 영화제를 현재 요청에 따라 조사한다. 기존 IP·완성작 재활용 우선, 신규 제작 금지 등을 과거 기록에서 현재 제약으로 가져오지 않는다.
- 주최 공고·공식 첨부·공식 제출 플랫폼을 우선한다. SNS·공고 전재·검색 색인은 발굴 경로로 구별한다. 공식 세부 요강 확인이 남으면 제작·참가 결정 전에 보완한다.
- 확인 상태는 `공식 핵심 확인 / 일부 추가 확인 / 공고 재확인`처럼 뜻이 보이게 쓴다. 공식 핵심 확인이 모든 첨부·약관 검증을 뜻하지 않게 한다. 자격 제한·보류와 실제 참가 결정은 별개다.
- **현금·상품권·포인트·크레딧·제작지원금**을 구별한다. 전체 시상과 AI 부문 시상을 섞지 않는다. 합계·마감·권리가 충돌하면 출처별 차이와 확인 필요를 남긴다.
- 최종·연장 마감, 종료 시각·시간대, 참가비, 규격, AI 활용·표시·증빙, 공개 의무, 미공개·타 대회 제출 제한, 이용권·철회 조건을 확인한다. 같은 작품의 여러 대회 출품은 조건 충돌을 먼저 점검한다.
- 기준일은 사용자 시간대의 날짜다. 해외 날짜만으로 사용자 시간대 자정 마감을 만들지 않는다. 한국시간 환산은 실제 종료 시각과 시간대가 확인된 경우에만 표시한다.
- 문서 개편일과 공고 확인일을 구별한다. 재조사하지 않은 항목의 확인일을 일괄 갱신하지 않는다. 작년 기록 기반 반복 예상은 `예상·감시`로 구분하며 현재 공고로 쓰지 않는다.
- 접근 제한·페이지 장애가 공모전 종료의 증거는 아니다. 접근 제한을 우회하지 않고 독립 출처로 보완하면 남은 미확인 조건을 표시한다. 수집 범위를 기록하되 모든 행사의 완전 수집을 보장하지 않는다.

## 누적 이력과 아카이브

- 일반 조사·정리마다 새 날짜별 보고서나 후보 목록을 만들지 않는다. `조사·정리 기록/`의 **하나의 누적 이력 문서**에서 `작업일 / 작업 / 결과 / 상세 링크` 목록과 필요한 상세를 추가한다. 같은 날 여러 작업은 제목으로 구별한다.
- 이전 날짜별 기록을 통합할 때는 원문·맥락을 보존하고 기존 제목 alias나 링크를 갱신한다. 스냅샷은 실질적인 보존 필요가 있을 때만 만들며 매 작업 자동 생성하지 않는다.
- 마감 경과가 확인된 노트는 기존 아카이브 폴더로 이동하고 원래 상태, 아카이브일, 근거·이전 위치를 기록한다. 최종·연장 접수가 남으면 활성 유지한다. 해외 시차·종료 시각이 불명확하면 `종료 시각 확인 필요`로 남긴다.
- 현재 요청이나 앞선 명시적 승인에 마감 아카이브가 포함돼 있으면 그 범위의 이동을 진행한다. 이동 승인이 없는 단순 조사 요청에서는 보관 위치를 임의 변경하지 않는다. 원문·파일명·기존 ID를 유지하고 목차·임베드·연결을 갱신한다.
- 마감·아카이브는 참가·수상·제작 완료를 뜻하지 않는다. 기본 상태는 `조사완료·참가미결정`; 실제 참가·제출은 사용자 결정이나 실행 증거로 갱신한다.

기존 개별 노트의 frontmatter는 보존한다. 새 노트가 필요한 경우에만 사용자 스키마에 맞춰 다음 필드를 참고한다.

```yaml
tags: [공모전/AI영상, 공모전/국내]
마감일: YYYY-MM-DD
상태: 조사완료·참가미결정
주최: ...
주관: ...
총상금: ...
출처: ...
확인일: YYYY-MM-DD
```

해당 부문 시상·마감 시각·시간대·참가비·권리·미확인 사항은 본문에 적는다. 기존 파일명의 날짜와 실제 최종 마감이 달라도 제목을 무조건 개명하지 않는다.

## 작업 마무리와 보고

1. 정보시트·후보 상세의 항목 수, 마감·시상·상태, ID·제목 앵커, 표 열 수와 링크 연결을 검증한다. 이동·통합 원문은 바이트나 해시로 확인한다.
2. 기존 누적 이력에 변경 요약, 이동 대응, 조사 범위, 검증 결과·한계와 다음 행동을 추가한다. 공유 인수인계가 있으면 짧게 연결한다.
3. 사용자 보고는 **정리된 결과와 문서 링크**를 먼저 보여준다. AI 운영 설명이나 긴 과정 로그를 반복하지 않는다. 임박한 마감은 필요할 때 따로 짚는다.
4. 연동 스프레드시트는 실제 갱신 여부만 보고한다. 조사·정리 요청으로 참가 신청·SNS 게시·메일 발송·결제·예약·자동 모니터를 실행하지 않는다. 별도의 명시적 요청 범위를 따른다.
