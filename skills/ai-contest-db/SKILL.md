# AI 영상 공모전 DB 관리

옵시디언 볼트의 공모전 폴더(예: `{{vault}}/!PARA/01_Project/AI 영상 공모전/`)에 있는 공모전 노트와 정보 시트를 관리한다. PARA 구조를 전제하지만 폴더 경로는 사용자 볼트에 맞게 조정.

## 파일 구조

- **정보 시트:** `AI 영화제 정보 시트.md` — 전체 현황판. "운영 기준" / "진행계획 후보" 표 / "아카이브/기록" 표 / Changelog로 구성.
- **개별 노트:** `{M월 D일} - {공모전명}.md` (예: `7월 30일 - ○○ AI 영상 광고·숏폼 공모전.md`)
- 마감 종료된 노트는 `!PARA/04_Archive/공모전·영화제 지원이력/`로 이동하거나 상태만 아카이브로 변경 (이동 전 사용자에게 확인 — 파일 이동/삭제는 사전 동의 필수).

## 개별 노트 frontmatter 스키마

```yaml
tags: [공모전/AI영상, 공모전/국내 또는 공모전/해외, 진행계획 또는 아카이브]
마감일: YYYY-MM-DD
상태: 계획후보 | 보류 | 아카이브
주최: ...
주관: ...
총상금: ...
출처: (공식 URL)
```

본문: `## 공모 개요`(진행 기간, 결과 발표, 참가 대상, 부문, 형식, 제출 가능 수, 공식 링크) + `## 전략 메모`(제출 현실성, 규격에 맞는 접근 방식, 선행 조건).

## 진행계획 후보 표 컬럼

| 상태 | 우선 | 마감 | 공모전 | 유형 | 제출/규격 | 실행 메모 | 링크 |

- 상태: 계획 / 보류. 우선순위: A/B/C.
- 개별 노트가 있으면 공모전 칸은 `[[위키링크]]`.

## 운영 기준 (시트의 기준 유지·갱신)

- **마감 지난 공모전은 아카이브로.** frontmatter `상태: 아카이브` + 아카이브 날짜 추가, 시트의 아카이브 표로 이동.
- **보류 = 공식 원문 미확인.** 검색 흔적만 있는 공모전은 보류로 두고 **"원문 확인 전 제작 착수 금지"** 원칙 유지. 해외 영화제는 약관·권리 조건·운영 법인·제출 링크 유효성까지 확인 (예: 제출 링크 404면 보류).
- **작년 기록 기반 반복 예상 공모전**은 확정 공고가 아니므로 `예상/감시`로 분리.
- **기존 IP 활용 우선:** 공모전용 신규 제작보다 기존 IP·브랜딩 자산의 출품을 우선 검토 — 세부 판단은 사용자의 출품 전략 문서를 참고.
- D-Day 표기 시 기준일을 명시하고 시트 상단 `기준일` frontmatter도 갱신.

## 작업 순서

1. 시트와 폴더의 현재 상태를 읽는다.
2. 마감 경과 항목 → 아카이브 처리 목록 제안 (이동은 동의 후).
3. 진행 중 항목 → 마감·D-Day·링크 유효성 갱신, 전략 메모 보강.
4. 신규 공모전 리서치 시 → 공식 원문 확인된 것만 개별 노트 생성, 미확인은 보류로 시트에만 등재.
5. 시트의 진행계획 표·아카이브 표·Changelog 갱신 (Changelog에 날짜와 변경 요약 추가).
6. 연동 스프레드시트가 시트에 링크되어 있으면 "스프레드시트도 갱신 필요"를 보고에 포함 (직접 수정은 요청 시에만).

## 완료 보고

변경 요약을 표로: 아카이브 이동 n건 / 갱신 n건 / 신규 n건, 마감 임박(D-7 이내) 항목은 ⚠️ 표시.
