# 출처와 개량 내역

이 스킬은 독자적으로 처음부터 만든 것이라고 주장하지 않는다. 아래 공개 스킬을 참고해 한국어 회의와 옵시디언 실행 기록에 맞게 개량한 파생 작업이다.

- 원본: `meeting-notes`, Claude Office Skills Contributors
- 저장소: https://github.com/claude-office-skills/skills/tree/9c4c7d5cd2813a8936bf2c9fdb174ea883b85a11/meeting-notes
- 원본 라이선스: MIT
- 변경: 일반 회의 요약을 사실·논의·결정·약속·실행·미해결 질문으로 분리하고, 담당자/기한 비추정, 한국어 존칭, 옵시디언 PARA 라우팅, 외부 반영 승인 경계를 추가했다.
