# B2B 견적/클라이언트 문의 분석

AI 활용 애니메이션·콘텐츠 제작 스튜디오의 B2B 외주 문의를 분석하고 견적을 구성하는 스킬.

## 작업 흐름

1. **문의 분석**: 클라이언트가 제공한 정보를 정리 (범위, 수량, 납기, 산출물)
2. **누락 정보 체크리스트 작성**: 아래 표준 체크리스트로 확인
3. **회신 초안 작성**: 누락 정보를 요청하는 메일 (korean-business-message 스킬의 톤 규칙 준수)
4. **견적 산출**: 모듈형 견적으로 구성

## 표준 누락 정보 체크리스트

문의 접수 시 반드시 확인할 항목:

- [ ] **범위/수량**: 미션·컷·캐릭터·모션 수량, 에피소드 수
- [ ] **산출물 스펙**: 해상도, 프레임레이트, 파일 포맷, 러닝타임
- [ ] **개발사 유무**: 별도 개발사가 프로그래밍을 담당하는가? → 담당 시 납품 포맷 확인 (Spine / Lottie / PNG 시퀀스 / 리깅 기반 여부)
- [ ] **AI 사용 허가**: AI 툴 사용 가능 여부, 계약서상 명시 필요 여부
- [ ] **산출물 재사용 범위**: 제작물의 2차 활용·포트폴리오 사용 가능 범위
- [ ] **소스 납기**: 클라이언트 측 원본 소스(일러스트, IP 에셋, 게임 푸티지 등) 전달 기한 — 킥오프 일자에 연동해 구체적 날짜로 요구
- [ ] **음원**: BGM/SFX가 신규 작곡인지 라이브러리 편집인지 (Artlist 등 라이선스 옵션 안내)
- [ ] **IP 권리**: 원저작권 확인 주체 (통상 클라이언트 책임 — 단, 계약서에 명시)
- [ ] **피드백 라운드**: 수정 횟수 상한

## 견적 구성 원칙

1. **모듈형 견적**: 단일 총액이 아닌 항목별 분해 견적 제시 → 클라이언트가 범위 조정으로 예산을 맞출 수 있게 함
2. **핵심 변수 명시**: 견적 변동 폭이 큰 변수를 먼저 파악
   - 캐릭터 수 × 캐릭터당 모션 수 (최대 변수)
   - BGM 신규 작곡 vs 라이브러리 편집
   - 업스케일 원본 수량, 신규 일러스트 분량
   - 개발사의 리깅 포맷 요구 여부
3. **러시 프리미엄**: 촉박한 일정은 저가 수주 이유가 아니라 할증 근거. 압축 일정 = 러시 비용 명시
4. **저가 수주 금지**: 일정이 빠듯할수록 견적을 깎지 말 것

## 단가 산출 원칙

- 초당/분당 단가 계약 구조는 내부적으로 **리소스 단위 원가**(작업자 시간 × 단계별 공수)를 먼저 잡은 뒤 회신할 것
- 과거 유사 사례가 있으면 그 단가를 기준선으로 삼되, 범위 차이(캐릭터 수·모션 수·음원·개발사 연동)를 반드시 보정
- 사용자의 실제 단가표는 이 스킬에 두지 않고 별도 비공개 문서(옵시디언·스프레드시트 등)에서 참조

## 협상/커뮤니케이션 팁

- 첫 회차는 클라이언트 제시 예산으로 진행하되, 실투입 공수 기반으로 차기 재협상 여지를 명시하는 전략이 유효
- 견적 논의는 실제 에피소드 샘플을 놓고 화상 미팅으로 진행하는 방식이 효과적
